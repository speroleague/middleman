# Cline context efficiency

`AGENTS.md` is the repository's authoritative workflow and routing guide. Follow it without restating or duplicating its rules.

- Use Cline's task notes and checkpoints for work that spans sessions.
- Keep command output narrow: use targeted searches, bounded file ranges, focused tests, and concise failure excerpts.
- Do not load generated files, dependencies, caches, logs, or ignored paths unless the task explicitly requires it.
- Add path-scoped rules as separate files in this directory when a repository needs frontend, database, security, or operational guidance that should not be loaded for every task.
